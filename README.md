# 💰 Projeto ContaBancaria

Bem-vindo(a) ao meu projeto **ContaBancaria**! 🚀  
Este é um sistema simples desenvolvido em **Java** no **IntelliJ IDEA**, criado com o objetivo de praticar conceitos fundamentais da linguagem.

---

## 🧩 Funcionalidades

✨ Criação de conta bancária  
💵 Depósito de valores  
💸 Saque de valores  
📊 Exibição de saldo e informações da conta  

---

## 🧠 Tecnologias utilizadas

- ☕ **Java**
- 🧰 **IntelliJ IDEA**

---

## 🧪 Como executar o projeto
Main.java

=== Conta Bancária ===

Digite o nome do titular: Suelem

Digite o valor inicial: 2.500

Deposite um valor: 200.00

Saque um valor: 100.00

Saldo atual: 600.00
